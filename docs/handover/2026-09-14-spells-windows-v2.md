**Two things stay hand-written, and both are named in the script.** The 15
`ANCHORS` are copied through byte-identical, because a state id is
`<class>-<round(t)>` of the frames a window holds: widening an existing range
renames every state in it, orphans its review crops and costs another full VLM
read. And `LABELS` still carries the demo character's class per range — the
spellbook never names it. Every new label was read off the sweep crops in
`work/priest-search/new-windows/`: the page heading where there is one, the tab
strip and the General page's racials where there is not.

## 3. The merge contract of `build`

`build` now reads the published `data/spells/<class>.json` and merges into it:

* a spell id already published keeps its **name, tab, icon and `source`** — so
  the review crop a reviewer has already looked at stays valid — and may only
  *gain* ranks, a tab it did not have, and tooltips whose description text is
  new;
* a record with `source.reviewed: true` is not touched at all;
* tabs, `coverage.pagesSeen`, `coverage.windows` and `notes` are unioned (a note
  whose opening 48 characters the new run also writes counts as superseded, so
  the rewritten "where the class label comes from" note does not double);
* a class file therefore cannot shrink. D-3's "fewer records than on disk is a
  regression" guard survives for `--no-merge`, where it still skips the class.

Verified against the pre-run files: **0 ids and 0 crop paths lost** in any class.
The six crops `prune_crops` deleted were already unreferenced litter from the
2026-09-13 run (checked against the pre-run files before deleting).

## 6. Surprises and decisions

* **Anchoring the old windows was the whole trick.** The first design widened
  and re-derived every range from the sweep. It is tidier and it would have
  thrown away 213 page states, 765 review crops and about 20 minutes of VLM
  time, because a state id is a timestamp. Copying the 15 old ranges through
  untouched and clipping the new ones against them cost nine lines and made the
  whole re-run additive.
* **The class had to be read off the tab strip, not the page.** Three of the new
  windows are a bare *General* page, which names no class. Correlating the whole
  tab strip against known pages was useless — the selected-tab highlight
  dominates the score, and it matched a page that is itself mislabelled (finding
  3 above) at 0.994. Comparing the tab *icons* by eye settled all three in a
  minute: druid's blue paw / green leaf / purple star are nothing like shaman's,
  and `Pick Lock` on a General page means rogue whatever the race.
* **A name is not a sentence.** `merge_entry` ran the mid-sentence capital-I
  rule over the spell *name*, so the moment a name contained a capital-I word,
  `Elemental Insight` was published as `Elemental insight`. The rule exists for
  a two-letter `In`/`Its`; it is now capped at three characters inside a name.
  Nothing else in 410 rows was affected, which is why it survived two rounds of
  review.
* **The sweep's "17 missing appearances" is 21 runs.** The report grouped
  adjacent openings by hand. Deriving the table from the scores makes the
  question go away: 50 runs in, 50 runs covered, and the script says so.
* **06:20 is not the end of the source window.** The one warlock window after it
  (06:20:40-06:22:13, Demonology plus Affliction and Destruction) is worth 38
  entries and 20 tooltips on its own — more than a third of everything this
  re-run added. `CLAUDE.md` §Decisions and `docs/PLAN.md` still give the source
  window as 03:00:00-06:20:00; for the spellbook it ends at 06:22:13.
